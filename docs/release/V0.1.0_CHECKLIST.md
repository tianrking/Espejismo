# v0.1.0 Release Checklist

## Required

| Area | Command / Check | Expected |
| --- | --- | --- |
| Format | `cargo fmt --all --check` | clean |
| Lints | `cargo clippy --workspace --all-targets --all-features -- -D warnings` | clean |
| Tests | `cargo test --workspace --all-targets` | pass |
| Fuzz build | `cargo check --manifest-path fuzz/Cargo.toml` | pass |
| Config docs | `docs/deployment/CONFIG.md` matches `configs/examples/espejismo.toml` | yes |
| Release workflow | `.github/workflows/release.yml` completes full matrix | artifacts uploaded |

## Artifact Matrix

