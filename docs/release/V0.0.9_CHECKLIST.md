# v0.0.9 Release Checklist

This checklist is the release gate for `v0.0.9`. A release is ready only when
all required items are marked as passed for the target platform.

Legend for `Result`:

- `PASS`: verified and matched expected result.
- `FAIL`: command succeeded but output/behavior did not match expected.
- `N/A`: intentionally skipped for this platform or environment.

| Step | Command | Expected | Result |
|---|---|---|---|
| Local doctor | `espejismo-local --config espejismo.toml --doctor` | Includes local server resolution/bind checks | |
| Remote doctor | `espejismo-remote --config espejismo.toml --doctor` | Includes low-feature warnings or pass context | |
| Handshake probe | `espejismo-local --config espejismo.toml --probe-server` | `OK remote handshake succeeded` | |
| TUN check | `espejismo-local --config espejismo.toml --tun-enabled --tun-auto-route --tun-auto-dns --check-config` | Includes `Linux TUN auto-route requested` and `Linux TUN auto-DNS requested` | |
| Start TUN | `sudo espejismo-local --config espejismo.toml --tun-enabled --tun-auto-route --tun-auto-dns` | Tunnel starts, no route deadlock | |
| IPv4 TCP path | `curl --max-time 20 http://1.1.1.1/cdn-cgi/trace` | Successful response through tunnel | |
| DNS path | `curl --max-time 20 https://ifconfig.me` | Successful response with DNS resolution | |
| Remote self-protection | `ip rule show` and `ip route show table main` | Remote endpoint has direct rule, not looped into TUN | |
| Recovery | `sudo espejismo-local --config espejismo.toml --tun-route-cleanup` | Routes and DNS reverted | |
