# Acknowledgments

Espejismo is made possible by people who contribute code, report problems,
test releases, improve documentation, and share thoughtful feedback. Thank you
to everyone who has helped the project.

## Contributors

See the [GitHub contributors page](https://github.com/tianrking/Espejismo/graphs/contributors)
for the current list of repository contributors. The page is maintained by
GitHub and may not capture every kind of contribution.

We also thank users who file clear bug reports, help reproduce issues, test
changes on different platforms, and suggest improvements. These contributions
help make the project more useful and reliable.

## Open-source software

Espejismo builds on the work of the Rust ecosystem and many upstream open-source
projects. Their authors and maintainers make it possible to develop and
maintain secure, portable software. The project's dependency manifest and
lockfile identify the libraries used in each revision; see `Cargo.toml` and
`Cargo.lock` for details.

Mention here is an acknowledgment of upstream work, not an endorsement or
affiliation. Each dependency remains subject to its own license and project
terms.

## Recognition

Contributions are appreciated regardless of size. If you believe a
contribution is missing from the GitHub contributors page, please open an
issue with the relevant repository activity so it can be reviewed.
