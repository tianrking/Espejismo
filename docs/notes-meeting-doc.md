# Meeting notes template

## Findings and plan

The repository has templates for GitHub issues and pull requests, but no
reusable template for recording project meetings. Add
`docs/MEETING_NOTES_TEMPLATE.md` with meeting details, agenda, discussion and
decisions, action owners and dates, risks, and next-meeting preparation. Keep
it concise and mark unknown information as `TBD` so the record distinguishes
confirmed decisions from missing details.

Expected benefit is more consistent meeting records and clearer follow-up
ownership. This is a qualitative documentation improvement; no numerical
performance gain is expected or claimed. The template describes project
coordination only and does not change product behavior or positioning.

## Validation and outcome

- Reviewed `docs/DOCUMENTATION_STYLE.md`, `docs/POSITIONING.md`, and the
  existing issue and PR template notes for repository conventions.
- Confirmed the template uses a single title, descriptive sections, and a
  compact action table; no product claims or operational instructions were
  introduced.
- Documentation-only change: builds, tests, and benchmarks are not applicable.
  No runtime or performance change is claimed.
